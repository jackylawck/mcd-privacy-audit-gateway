🍔 MCD Privacy & Audit Gateway

面向麦当劳 MCP 生态的企业级安全网关 MVP。提供双向数据治理与不可变审计追踪。

🛡️ Inbound PII 遮蔽

基于确定性正则匹配，在用户 Prompt 接触外部工具前，动态抹除手机号与邮箱等敏感实体，落实数据最小化原则。

🚨 Outbound 注入粗筛

拦截 MCP Tool 返回值，执行 Unicode 规范化。检测恶意注入指令并硬阻断，同时对良性输出套用来源隔离标记 (Provenance Isolation)。

⛓️ 不可变审计链

结合 Event Hubs 单分区 FIFO 序列化与 Storage Account WORM 策略，辅以 Azure Managed Identity 确保身份不可否认性。

📝 诚实的安全契约

配备详尽的 Threat Model，诚实披露对称签名的生命周期矛盾与正则粗筛边界，展现 2026 年企业级治理高度。
